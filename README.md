# 모먼트 — 나의 작은 작업실

**날씨 확인, 간단한 계산, 할 일 정리, 집중 타이머를 한 화면에서 사용하는 웹 앱입니다.**

별도의 앱 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다. 컴퓨터와 휴대폰 화면에 맞춰 배치가 바뀝니다.

## 1. 앱 바로 열기

### 👉 [모먼트 사용하기](https://takgangmin.github.io/moment-app/)

위 링크가 **실제로 앱을 사용하는 주소**입니다. 지금 보고 있는 GitHub 페이지는 앱의 코드와 설명서를 보관하는 곳입니다.

> 자주 사용한다면 앱 주소를 브라우저 즐겨찾기에 추가해 두세요.

## 2. 기능별 사용법

| 기능 | 이렇게 사용하세요 |
| --- | --- |
| 오늘의 날씨 | 오른쪽 위 지역 목록에서 도시를 선택하면 기온, 체감 온도, 습도, 풍속을 볼 수 있습니다. |
| 내 위치 날씨 | **내 위치 사용**을 누르고 브라우저의 위치 접근 요청을 허용하세요. |
| 계산기 | 화면의 숫자·연산 버튼을 누르거나 키보드로 계산식을 입력하세요. |
| 오늘의 할 일 | 입력 칸에 할 일을 적고 **+** 또는 **Enter**를 누르세요. 체크하면 완료 처리되고, **×**를 누르면 삭제됩니다. |
| 집중 타이머 | **25분 집중 / 50분 집중 / 5분 휴식** 중 하나를 고른 뒤 **시작**을 누르세요. 멈춤·계속·초기화도 가능합니다. |
| 시계 | 사용 중인 기기의 시간과 날짜가 자동으로 표시됩니다. |

### 계산기 단축키

- `Enter` 또는 `=`: 계산 결과 보기
- `Backspace`: 마지막 글자 지우기
- `Esc`: 계산식 초기화
- 화면의 `AC`: 계산식 초기화
- `%`: 앞의 숫자를 100으로 나누기. 예를 들어 `50%`는 `0.5`입니다.

곱셈·나눗셈을 덧셈·뺄셈보다 먼저 계산합니다. 예를 들어 `2+3×4`의 결과는 `14`입니다. 할 일 입력 칸에 글을 쓰는 동안에는 계산기 단축키가 작동하지 않습니다.

### 알아두면 좋은 점

- **날씨:** 인터넷 연결이 필요하며 약 15분마다 새로 조회합니다. 화면에 표시된 기준 시각도 함께 확인하세요.
- **위치 권한:** 허용하지 않아도 도시를 직접 선택해 날씨를 볼 수 있습니다.
- **할 일 저장:** 같은 브라우저에서 앱을 다시 열면 이전 목록을 불러옵니다. 기기나 브라우저가 바뀌면 목록이 공유되지 않습니다.
- **저장 공간 삭제:** 브라우저의 사이트 데이터를 지우거나 시크릿 창을 닫으면 저장한 목록을 잃을 수 있습니다.
- **타이머:** 앱을 열어 둔 상태에서 사용하세요. 탭을 닫거나 새로고침하면 타이머는 초기화됩니다. 완료 시 화면으로 안내하며 알림음은 없습니다.

## 3. 내 컴퓨터에서 실행하기

인터넷에 배포하지 않고 파일을 직접 열어서 사용할 수도 있습니다.

1. 이 저장소 상단에서 **Code → Download ZIP**을 누릅니다.
2. 다운로드한 ZIP 파일의 압축을 풉니다.
3. 폴더 안의 **`index.html`**을 더블클릭해 브라우저로 엽니다.

Node.js 설치나 별도의 실행 명령은 필요하지 않습니다. 다만 날씨와 웹 폰트를 불러오려면 인터넷 연결이 필요하고, 파일을 직접 열었을 때는 브라우저 보안 설정에 따라 현재 위치 기능이 제한될 수 있습니다. 이 경우 배포된 앱 주소를 이용하거나 도시를 직접 선택하세요.

> 파일을 직접 열었을 때의 할 일 목록과 배포된 사이트의 할 일 목록은 서로 다르게 저장됩니다.

## 4. 어떤 파일을 수정하면 되나요?

```text
moment-app/
├─ index.html     ← 앱 화면, 디자인, 동작이 모두 들어 있는 파일
├─ README.md      ← 지금 보고 있는 설명서
└─ .gitignore     ← Git에 올리지 않을 파일을 정하는 설정
```

- **앱을 바꾸려면:** `index.html`을 수정하세요. HTML은 화면 구조, CSS는 디자인, JavaScript는 계산·날씨·타이머 같은 동작을 담당합니다. 이 앱은 세 가지가 한 파일에 들어 있습니다.
- **설명서를 바꾸려면:** `README.md`를 수정하세요.
- 처음 만들었던 상위 폴더의 `productivity.html`은 원본 사본입니다. **그 파일만 수정해도 배포 사이트가 바뀌지는 않습니다.** 실제 배포 대상은 이 저장소의 `index.html`입니다.

## 5. 수정한 내용을 GitHub와 앱에 반영하기

흐름은 **파일 수정 → 변경 확인 → 커밋 → 푸시 → 자동 배포**입니다.

| 용어 | 쉽게 말하면 |
| --- | --- |
| Git | 내 컴퓨터에서 파일의 변경 이력을 관리하는 도구 |
| GitHub | Git으로 관리하는 코드를 온라인에 보관하는 곳 |
| 커밋(commit) | 변경 내용을 설명과 함께 기록하는 것. 아직 내 컴퓨터에만 저장됩니다. |
| 푸시(push) | 내 컴퓨터의 커밋을 GitHub에 올리는 것 |
| GitHub Pages | 저장소의 HTML 파일을 실제 웹사이트로 공개해 주는 서비스 |
| GitHub CLI(`gh`) | 터미널에서 GitHub 로그인, 저장소 생성 등을 할 수 있는 도구 |

### 방법 A. 내 컴퓨터에서 수정하고 올리기

Git과 GitHub CLI 설치 및 첫 로그인은 이미 완료한 상태를 기준으로 합니다.

1. `moment-app` 폴더의 `index.html` 또는 `README.md`를 편집하고 저장합니다.
2. 새 PowerShell 창을 열고 **저장소 폴더로 이동**합니다. 아래 경로는 최초 설치한 컴퓨터 기준입니다. 다른 위치에 저장했다면 실제 경로로 바꾸세요.

```powershell
cd "C:\Users\NHI\Desktop\브라우저 자동화\moment-app"
```

3. 아래 명령을 **한 줄씩 순서대로** 실행합니다.

```powershell
git status
git add index.html README.md .gitignore
git diff --cached
git commit -m "앱과 설명서 업데이트"
git push
```

각 명령의 의미는 다음과 같습니다.

1. `git status`: 어떤 파일이 바뀌었는지 확인합니다.
2. `git add ...`: 이번 커밋에 포함할 파일을 선택합니다. 실제로 바뀐 파일만 반영됩니다.
3. `git diff --cached`: 선택한 파일에서 무엇이 바뀌었는지 확인합니다. 긴 화면이 나타나면 `q`를 눌러 나올 수 있습니다.
4. `git commit -m "..."`: 변경 내역을 기록합니다. 따옴표 안에는 무엇을 바꿨는지 적으면 됩니다.
5. `git push`: 기록한 변경 사항을 GitHub로 전송합니다.

> 이 저장소는 이미 GitHub에 연결되어 있습니다. 매번 `git init`, 저장소 생성, 로그인을 다시 할 필요는 없습니다. 비밀번호나 인증 토큰을 코드나 README에 적지 마세요.

### 방법 B. GitHub 웹사이트에서 간단히 수정하기

설명서의 문구 정도는 터미널 없이도 바꿀 수 있습니다.

1. [저장소](https://github.com/takgangmin/moment-app)에서 `README.md`를 엽니다.
2. 연필 모양 **Edit this file** 버튼을 누릅니다. 본인 계정으로 로그인되어 있어야 합니다.
3. 내용을 수정한 뒤 **Preview**로 미리 봅니다.
4. **Commit changes**를 누르고 변경 설명을 적어 저장합니다.

웹에서 수정한 뒤 내 컴퓨터에서도 작업하려면, **로컬 파일을 수정하기 전에** 저장소 폴더에서 `git pull --ff-only`를 실행해 최신 내용을 먼저 받아 오세요. 로컬에 저장하지 않은 작업이나 커밋하지 않은 변경이 있다면 먼저 확인하고, 오류가 나면 강제로 덮어쓰지 마세요.

## 6. 배포가 잘됐는지 확인하기

`main` 브랜치에 푸시하면 GitHub Pages 배포가 자동으로 시작됩니다. 직접 서버를 실행할 필요는 없습니다.

1. [Actions 페이지](https://github.com/takgangmin/moment-app/actions)를 엽니다.
2. 가장 최근의 **pages build and deployment** 작업을 확인합니다.
3. 초록색 체크 표시로 완료되면 [앱 주소](https://takgangmin.github.io/moment-app/)를 다시 엽니다.
4. 이전 화면이 보이면 Windows 기준 `Ctrl + F5`로 새로고침합니다.

배포에는 보통 수십 초에서 몇 분 정도 걸립니다. **README만 수정했다면 앱 화면은 바뀌지 않고 이 설명서가 바뀝니다.**

### 현재 배포 설정

첫 배포 설정은 이미 완료되어 있습니다. 확인할 때는 저장소의 **Settings → Pages → Build and deployment**로 들어가세요.

| 항목 | 설정값 |
| --- | --- |
| Source | Deploy from a branch |
| Branch | main |
| Folder | / (root) |
| 앱 주소 | https://takgangmin.github.io/moment-app/ |

## 7. 자주 생기는 문제

| 상황 | 확인할 내용 |
| --- | --- |
| 날씨가 표시되지 않아요 | 인터넷 연결을 확인하고 날씨 카드의 **다시 시도**를 누르세요. 외부 날씨 서비스 장애일 수도 있습니다. |
| 내 위치를 찾지 못해요 | 브라우저의 위치 권한을 확인하세요. 권한을 주기 어렵다면 도시를 직접 선택하면 됩니다. |
| 다른 기기에서 할 일이 안 보여요 | 할 일은 브라우저에만 저장되며 기기 간 동기화를 지원하지 않습니다. |
| `git` 또는 `gh` 명령을 찾을 수 없다고 나와요 | 설치 후 열려 있던 터미널을 닫고 새 PowerShell 창에서 다시 실행하세요. 계속 안 되면 설치 및 PATH 설정을 확인하세요. |
| `not a git repository`가 나와요 | 현재 폴더가 저장소가 아닙니다. `cd` 명령으로 `moment-app` 폴더에 들어갔는지 확인하세요. |
| `nothing to commit`이 나와요 | 새로 기록할 변경이 없다는 뜻입니다. 파일을 실제로 수정하고 저장했는지 확인하세요. |
| 푸시할 때 인증 오류가 나요 | `gh auth status`로 확인하고, 필요하면 `gh auth login`으로 로그인한 뒤 `gh auth setup-git`을 실행하세요. |
| 푸시가 `rejected`로 거절돼요 | GitHub에 내 컴퓨터가 아직 받지 않은 변경이 있을 수 있습니다. `git status`를 확인하고 오류 원인을 살펴보세요. `--force`로 강제로 덮어쓰지 마세요. |
| 푸시했는데 화면이 그대로예요 | Actions 배포 완료 여부와 수정한 파일이 `moment-app/index.html`인지 확인한 뒤 새로고침하세요. |

## 8. 외부 서비스와 데이터

- **날씨:** [Open-Meteo](https://open-meteo.com/). API 키 입력 없이 사용하며, 선택한 도시의 좌표로 날씨를 요청합니다. **내 위치 사용**을 허용하면 기기에서 확인한 좌표를 날씨 조회에 사용합니다.
- **글꼴:** Google Fonts의 DM Sans, Noto Sans KR. 불러오지 못하면 기기의 기본 글꼴로 표시됩니다.
- **할 일과 선택한 도시:** 현재 브라우저의 로컬 저장소에 저장합니다. 앱에서 별도의 계정 서버나 데이터베이스로 전송하지 않습니다.

이 저장소의 코드는 공개되어 있지만, **브라우저에 입력한 할 일 목록이 저장소에 자동으로 올라가지는 않습니다.**
